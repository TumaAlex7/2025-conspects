**Определение.** Путь из $(0,0)$ в $(2k, 0)$ называется *путём Дика*, если каждый шаг из $(a, b)$ идёт в $(a+1, b+1)$ или $(a+1, b-1)$ и не опускается ниже оси $OX$

**Теорема.** $c_n$ - количество путей Дика из $(0,0)$ в $(2n, 0)$  
**Док-во 1.** рекурентное определение $\Leftrightarrow c_n = \#$ путей  
*Док-во* по индукции  
База: $n = 0 \Rightarrow c_0 = 1 \qquad $
Переход:  
$c_n = c_0 c_{n-1} + c_1 c_{n-2} + \ldots + c_{n-1}$  
$c_k = \#$ путей для $k < n$  

Посчитаем количество путей Дика длины $2n$  
$P$ - путь Дика длины $2n$  
есть минимальное $k$, такое что $(2k, 0) \in P$  

для отрезка $[1, 2k-1]$ - все точки не ниже $y = 1$  
это путь Дика длины $2(k-1)$  
Путь Дика на отрезке $[2k, 2n]$ - это путь Дика длины $2(n-k)$  

$\#$ путей Дика длины $2n$, у которых первая точка касания $2k$ = $c_{k-1} \cdot c_{n-k}$  
$\Rightarrow \#$ путей Дика длины $2n$ = $\underset{k=1}{\overset{n}{\sum}} c_{k-1} \cdot c_{n-k} = c_n$  
**Док-во 2.** комбинаторное  
$C_{2n}^{n} - C_{2n}^{n+1} = \#$ путей Дика длины $2n$  
$C_{2n}^{n}$ - всего путей из $(0,0)$ в $(2n, 0)$  
Надо почситать сколько путей не Дика  
$p$ - не путь Дика в $(2n, 0)$  
Часть после перехода под ось $OX$ отразим относительно $y = -1$  
$\tilde{p}$ - это полученный путь с оттраженной частью  
Up $\leftrightarrow$ Down  
$\tilde{p}$ из $(0,0)$ в $(2n, -2n)$  
$\Rightarrow \# \tilde{p} = C_{2n}^{n+1}$  
$\Rightarrow \#$ путей, которые пересекают ось $OX$ $= C_{2n}^{n+1}$  
$\Rightarrow \#$ путей Дика $ = C_{2n}^{n} - C_{2n}^{n+1}$
