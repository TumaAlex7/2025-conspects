**Определение.**  $n, a_1+a_2+ \ldots + a_l = n \quad 0 \leq a_i$

- $A_i$ - непересекающиеся по парно
- $|A_i| = a_i$  
**Замечание.**  $\left( \begin{aligned} n \\ k \end{aligned} \right) = \left( \begin{aligned} n \\ k, n-k \end{aligned} \right)$  

**Теорема.**  
$(x_1 + x_2 + \ldots + x_l)^n = \sum \left( \begin{aligned} n \\ a_1, a_2, \ldots, a_l \end{aligned} \right) x_1^{a_1} x_2^{a_2} \ldots x_l^{a_l}$  
**Док-во.** тоже самое  
$(x_1+x_2+ \ldots + x_l)(x_1+x_2+ \ldots + x_l) \ldots (x_1+x_2+ \ldots + x_l)$

**Теорема.**  
$\left( \begin{aligned} n \\ a_1, a_2, \ldots, a_l \end{aligned} \right) = \frac{n!}{a_1! a_2! \ldots a_l!}$  
**Док-во.**  
$S_n \rightarrow$ множество разбиений $\{1,2,3,$\ldots$,n\}$ на $A_1 \cup A_2 \cup \ldots \cup A_l : |A_i| = a_i$  
у каждого прообраза размера $a_1!, a_2!, \ldots, a_l! \Rightarrow n! = \left( \begin{aligned} n \\ a_1, a_2, \ldots, a_l \end{aligned} \right) \cdot a_1! a_2! \ldots a_l!$
