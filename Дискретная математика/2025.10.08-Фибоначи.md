$F(x) = \sum_{i = 0}^{\infty} a_i x^i$  
$F(x) = a_0 + a_1 x + \ldots + a_{k-1} x^{k-1} + a_k x^k + a_{k+1} x^{k+1} + \ldots = a_0 + a_1 x + \ldots + a_{k-1} x^{k-1} + \sum_{n = 0}^{\infty} a_{n+k} x^{n+k} = a_0 + a_1 x + \ldots + a_{k-1} x^{k-1} + \sum_{n = 0}^{\infty} (b_k a_n + b_{k-1} a_{n+1} + \ldots + b_1 a_{n+k-1}) \cdot x^{n+k} = a_0 + a_1 x + \ldots + a_{k-1} x^{k-1} + \sum_{n = 0}^{\infty} (b_k x^k a_n x^n + b_{k-1} x^{k-1} a_{n+1} x^{n+1} + \ldots) = a_0 + a_1 x + \ldots + a_{k-1} x^{k-1} + (\sum_{n = 0}^{\infty} a_n x^n) \cdot b_k x^k + (\sum_{n = 1}^{\infty} a_n x^n) \cdot b_{k-1} x^{k-1} + \ldots + (\sum_{n = k-1}^{\infty} a_n x^n) \cdot b_1 x = p(x) + f(x) \cdot (b_k x^k + b_{k-1} x^{k-1} + \ldots + b_1 x)$, где $p(x)$ - какой-то многочлен степени не выше $k-1$  
Следовательно $f(x) = \frac{p(x)}{1 - b_1 x - b_2 x^2 - \ldots - b_k x^k}$  

**Факт** $\frac{p(x)}{q(x)} = (\sum \frac{c_{\epsilon, d}}{(x-\epsilon)^d}) + r(x)$  
$c_{\epsilon, d} \in \mathbb{C}\qquad \epsilon$ - корни $q(x)$ причём $c_{\epsilon, d} = 0$, если $d >$ кратности корня  
$q(x) = (x - \epsilon_1)^{d_1} (x - \epsilon_2)^{d_2} \ldots (x - \epsilon_k)^{d_k}$  
$a(x), b(x)$ - взаимно просты  
$a(x) \cdot s(x) + b(x) \cdot t(x) = 1$  
$\frac{1}{a(x) b(x)} = \frac{t(x)}{a(x)} + \frac{s(x)}{b(x)}$  
$\frac{p(x)}{q(x)} = \sum \frac{t_i(x)}{(x - \epsilon_i)^{d_i}}$  
Этого достаточно, чтобы решать рекуренты.

**Лемма** Если $\xi$ - корень кратности $\geq s$, то $r_{s-1} (n) \cdot \xi^n$ - решение рекуренты
