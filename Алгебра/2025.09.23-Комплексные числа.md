# Комплексные числа

## Комплексное сопряжение
$\mathbb{C} \to \mathbb{C}$  
$a+bi \mapsto a-bi$  
$z \mapsto \overline{z}$  

**Определение.** Пусть $K,L$ - поля, отображение $\varphi: K \to L$ называется *изоморфизмом* полей, если:
1. $\varphi$ - биекция
2. $\forall a,b \in K: \varphi(a+b) = \varphi(a) + \varphi(b)$
3. $\forall a,b \in K: \varphi(a \cdot b) = \varphi(a) \cdot \varphi(b)$

*Автоморфизмом* поля $K$ называется изоморфизм поля $K \to K$  

### Свойства комплексного сопряжения

**Предложение.** Комплексное сопряжение - автоморфизм поля $\mathbb{C}$

1. $\overline{\overline{z}} = z \quad \forall z \in \mathbb{C} \Rightarrow$ комплексное сопряжение обратимое
   $$\sigma: z \mapsto \overline{z}$$  
   $$\sigma \circ \sigma = \text{id}_{\mathbb{C}} \Rightarrow \sigma^{-1} = \sigma$$   

2. $$\begin{aligned}
   \overline{z_1 + z_2} &= \overline{z_1} + \overline{z_2} \\
   \overline{z_1 \cdot z_2} &= \overline{z_1} \cdot \overline{z_2}
   \end{aligned}$$

   **Док-во:** $z_1 = a_1 + b_1i, \quad z_2 = a_2 + b_2i$  
   
   $$\begin{aligned}
   \overline{z_1 + z_2} &= \overline{(a_1 + a_2) + (b_1 + b_2)i} \\
   &= (a_1 + a_2) - (b_1 + b_2)i \\
   &= (a_1 - b_1i) + (a_2 - b_2i) \\
   &= \overline{z_1} + \overline{z_2}
   \end{aligned}$$
   
   $$\begin{aligned}
   \overline{z_1 \cdot z_2} &= \overline{a_1a_2 - b_1b_2 + (a_1b_2 + a_2b_1)i} \\
   &= a_1a_2 - b_1b_2 - (a_1b_2 + a_2b_1)i
   \end{aligned}$$
   
   $$\begin{aligned}
   \overline{z_1} \cdot \overline{z_2} &= (a_1 - b_1i) \cdot (a_2 - b_2i) \\
   &= a_1a_2 - b_1b_2 + (-a_1b_2 - a_2b_1)i \\
   &= a_1a_2 - b_1b_2 - (a_1b_2 + a_2b_1)i
   \end{aligned}$$

### Дополнительные свойства

**Упражнение.** Доказать, что у $\mathbb{R}$ есть только единственный автоморфизм - тождественное отображение

Для $z = x + yi, \quad x,y \in \mathbb{R}$:
- $\text{Re}(z) = x$ - вещественная часть $z$  
- $\text{Im}(z) = y$ - мнимая часть $z$

**Дополнительные свойства:**
- $z = \overline{z} \Leftrightarrow z \in \mathbb{R}$
- $z = -\overline{z} \Leftrightarrow z \in i\mathbb{R}$ ($z$ - чисто мнимое число)  
- $z = x + yi \Rightarrow z \cdot \overline{z} = x^2 - (yi)^2 = x^2 + y^2 \in \mathbb{R}$  
- геометрически комплексное сопряжение - симметрия относительно оси $OX$ (абсцисс)

## 2. Тригонометрическая форма комплексного числа

### Модуль комплексного числа

**Определение.** *Модулем* комплексного числа $z = x + yi \in \mathbb{C}$ называется число $|z| = \sqrt{x^2 + y^2}$

**Свойства модуля:**

1. Для $z \in \mathbb{R}$ новое понятие совпадает со старым
2. $|z| \geq 0; \quad |z| = 0 \Leftrightarrow z = 0$
3. $|\overline{z}| = |z|$
4. $|z| = \sqrt{z \cdot \overline{z}}$
5. $|z|^2 = z \cdot \overline{z} \Rightarrow |z|^{-1} = \frac{\overline{z}}{|z|^2} \quad (z \neq 0)$

6. **Мультипликативность:** $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$
   
   **Док-во:**  
   $z_1 = x_1 + y_1i, \quad z_2 = x_2 + y_2i$  
   $$|z_1 \cdot z_2|^2 = (x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2 = x_1^2x_2^2 + y_1^2y_2^2 + x_1^2y_2^2 + x_2^2y_1^2$$  
   $$|z_1|^2 \cdot |z_2|^2 = (x_1^2 + y_1^2)(x_2^2 + y_2^2) = x_1^2x_2^2 + y_1^2y_2^2 + x_1^2y_2^2 + x_2^2y_1^2$$

7. **Неравенство треугольника:** $z_1,z_2 \in \mathbb{C} \Rightarrow |z_1 + z_2|^2 \leq (|z_1| + |z_2|)^2$  
   
   **Док-во:**  
   $z_1 = x_1 + y_1i, \quad z_2 = x_2 + y_2i$  
   $$|z_1 + z_2|^2 = (x_1 + x_2)^2 + (y_1 + y_2)^2 = x_1^2 + x_2^2 + y_1^2 + y_2^2 + 2x_1x_2 + 2y_1y_2$$  
   $$(|z_1| + |z_2|)^2 = |z_1|^2 + |z_2|^2 + 2|z_1| \cdot |z_2| = x_1^2 + y_1^2 + x_2^2 + y_2^2 + 2|z_1 \cdot z_2|$$  
   $$|z_1 \cdot z_2|^2 = (x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2 = x_1^2x_2^2 + y_1^2y_2^2 + x_1^2y_2^2 + x_2^2y_1^2$$  
   $$(x_1x_2 + y_1y_2)^2 = x_1^2x_2^2 + y_1^2y_2^2 + 2x_1x_2y_1y_2 \leq 2x_1^2x_2^2 + 2y_1^2y_2^2 + x_1^2y_2^2 + x_2^2y_1^2$$

8. **Деление:** $z_1,z_2 \in \mathbb{C}, \quad z_2 \neq 0 \Rightarrow \left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$  
   
   **Док-во:**  
   $z_1 = z_2 \cdot \frac{z_1}{z_2} \Rightarrow |z_1| = |z_2| \cdot \left|\frac{z_1}{z_2}\right|$

### Аргумент комплексного числа

**Определение.** Пусть $z \in \mathbb{C}, \quad z \neq 0$, тогда *аргументом* $z$ называется число $\phi \in \mathbb{R}$, такое что $z = |z| \cdot \cos \phi + i \cdot |z| \cdot \sin \phi$

**Предложение.** Пусть $z \in \mathbb{C}\setminus\{0\}$  
1. Аргумент $z$ существует.
2. Пусть $\varphi$ - аргумент $z$, $\varphi' \in \mathbb{R}$. Тогда $\varphi'$ - аргумент $z \Leftrightarrow \varphi' - \varphi = 2\pi k, \quad k \in \mathbb{Z}$

**Док-во:**  
$z = x + yi, \quad x,y \in \mathbb{R}$  
$-|z| \leq x \leq |z| \Rightarrow -1 \leq \frac{x}{|z|} \leq 1 \Rightarrow \exists \psi \in \mathbb{R} : \cos \psi = \frac{x}{|z|}$  
$$(\sin \psi)^2 + (\cos \psi)^2 = 1 \Rightarrow (\sin \psi)^2 + \frac{x^2}{x^2 + y^2} = 1 \Rightarrow (\sin \psi)^2 = 1 - \frac{x^2}{x^2 + y^2} = \frac{y^2}{x^2 + y^2} \Rightarrow \sin \psi = \pm \frac{y}{\sqrt{x^2 + y^2}}$$

1. $\sin \psi = \frac{y}{\sqrt{x^2 + y^2}}$  
  $|z| \cdot \cos \psi + i \cdot |z| \cdot \sin \psi = x + yi = z$  
  Таким образом $\psi$ - аргумент $z$  

2. $\sin \psi = -\frac{y}{\sqrt{x^2 + y^2}}$  
  $|z| \cdot \cos(-\psi) + i \cdot |z| \cdot \sin(-\psi) = x + yi = z$  
  Таким образом $-\psi$ - аргумент $z$  

**Обратное направление ($\Leftarrow$):**  
$\varphi' = \varphi + 2\pi k, \quad k \in \mathbb{Z} \Rightarrow \cos \varphi' = \cos \varphi, \quad \sin \varphi' = \sin \varphi \Rightarrow \varphi'$ - аргумент $z$

**Прямое направление ($\Rightarrow$):**  
$z = |z| \cdot \cos \varphi + i \cdot |z| \cdot \sin \varphi = |z| \cdot \cos \varphi' + i \cdot |z| \cdot \sin \varphi'$  
$|z| \neq 0 \Rightarrow \begin{cases} \cos \varphi = \cos \varphi' \\ \sin \varphi = \sin \varphi' \end{cases}$  

На $[-\pi, \pi] = I$:  
$\cos \varphi' = \cos \varphi, \quad \varphi, \varphi' \in I \Rightarrow \left[\begin{aligned} \varphi = \varphi' \\ \varphi = -\varphi' \end{aligned}\right.$

$$\left[\begin{aligned} 
&\begin{cases} \varphi' = \varphi + 2\pi k, \quad k \in \mathbb{Z} \\ \sin \varphi' = \sin \varphi \end{cases} \\ 
&\begin{cases} \varphi' = -\varphi + 2\pi k, \quad k \in \mathbb{Z} \\ \sin \varphi' = \sin \varphi \end{cases} 
\end{aligned} \right. \Rightarrow \left[ \begin{aligned} 
& \varphi' = \varphi + 2\pi k, \quad k \in \mathbb{Z} \\ 
& \begin{cases} \varphi' = -\varphi + 2\pi k \\ \varphi = l\pi, \quad l \in \mathbb{Z} \end{cases} 
\end{aligned} \right. \Rightarrow \varphi' = \varphi + 2\pi k, \quad k \in \mathbb{Z}$$

### Свойства аргументов

**Предложение.**  
1. $\text{арг}(\overline{z}) = -\text{арг}(z)$
2. $\text{арг}(z_1 \cdot z_2) = \text{арг}(z_1) + \text{арг}(z_2)$
3. $\text{арг}\left(\frac{z_1}{z_2}\right) = \text{арг}(z_1) - \text{арг}(z_2)$

**Док-во:**  
1. $\text{арг} z = \varphi$  
   $z = |z| \cdot (\cos \varphi + i \cdot \sin \varphi)$  
   $\overline{z} = |z| \cdot (\cos (\varphi) - i \cdot \sin (\varphi)) = |z| \cdot (\cos (-\varphi) + i \cdot \sin (-\varphi))$  
   $-\varphi = \text{арг}(\overline{z})$

2. $\varphi_1 = \text{арг} z_1, \quad \varphi_2 = \text{арг} z_2$  
   $$\begin{aligned}
   z_1 \cdot z_2 &= |z_1| \cdot (\cos \varphi_1 + i \cdot \sin \varphi_1) \cdot |z_2| \cdot (\cos \varphi_2 + i \cdot \sin \varphi_2) \\
   &= |z_1| \cdot |z_2| \cdot ((\cos \varphi_1 \cos \varphi_2 - \sin \varphi_1 \sin \varphi_2) + i \cdot (\cos \varphi_1 \sin \varphi_2 + \sin \varphi_1 \cos \varphi_2)) \\
   &= |z_1 \cdot z_2| \cdot (\cos (\varphi_1 + \varphi_2) + i \cdot \sin (\varphi_1 + \varphi_2))
   \end{aligned}$$
   $\Rightarrow \varphi_1 + \varphi_2 = \text{арг}(z_1 \cdot z_2)$

3. $z_1 = z_2 \cdot \frac{z_1}{z_2} \Rightarrow \text{арг}(z_1) = \text{арг}(z_2) + \text{арг}\left(\frac{z_1}{z_2}\right) \Rightarrow \text{арг}\left(\frac{z_1}{z_2}\right) = \text{арг}(z_1) - \text{арг}(z_2)$

## 3. Формула Де Муавра

**Следствие (Формула Де Муавра).** Пусть $z \in \mathbb{C}\setminus\{0\}, \quad n \in \mathbb{Z}, \quad z = r \cdot (\cos \varphi + i \cdot \sin \varphi)$

Тогда $z^n = r^n \cdot (\cos (n\varphi) + i \cdot \sin (n\varphi))$

**Замечание.** Пусть $z = r \cdot (\cos \varphi + i \cdot \sin \varphi), \quad r,\varphi \in \mathbb{R}, \quad r > 0$  
Тогда $r = |z|$ и $\varphi = \text{арг} z$

**Док-во замечания:**  
$|z| = \sqrt{(r \cos \varphi)^2 + (r \sin \varphi)^2} = \sqrt{r^2 (\cos^2 \varphi + \sin^2 \varphi)} = \sqrt{r^2} = r \Rightarrow \text{арг} z = \varphi$ по определению аргумента

**Док-во формулы Де Муавра:**  
1. **Пусть $n>0$** - индукция по $n$:
   - База $n=1$ - тривиально  
   - Переход $n \mapsto n+1$:  
   $$\begin{aligned}
   z^{n+1} &= z^n \cdot z = r^n \cdot (\cos (n\varphi) + i \cdot \sin (n\varphi)) \cdot r \cdot (\cos \varphi + i \cdot \sin \varphi) \\
   &= r^{n+1} \cdot ((\cos ((n+1)\varphi) + i \cdot \sin ((n+1)\varphi)))
   \end{aligned}$$

2. **Пусть $n=0$:** $z^0 = 1$

3. **Пусть $n<0$:**  
   $z^n = (z^{-n})^{-1} = \frac{1}{r^{-n}}$  
   $z^{-n} = r^{-n} \cdot (\cos (-n\varphi) + i \cdot \sin (-n\varphi))$ из первого случая  
   $\frac{1}{r^{-n}} = \frac{1}{r^{-n}} \cdot (\cos (0-(-n)\varphi) + i \cdot \sin (0-(-n)\varphi)) = r^n \cdot (\cos (n\varphi) + i \cdot \sin (n\varphi))$

## 4. Корни из комплексного числа

**Пример.** Найти корни уравнения $z^2 = 5 - 12i$

**Решение:**  
$(x+yi)^2 = 5 - 12i$  
$(x^2 - y^2) + 2xyi = 5 - 12i$  

$$\begin{cases} 
x^2 - y^2 = 5 \\ 
2xy = -12 
\end{cases} \Leftrightarrow \begin{cases} 
x^2 - \frac{36}{x^2} = 5 \\ 
y = \frac{-6}{x} 
\end{cases}$$

$t = x^2$  
$t^2 - 5t - 36 = 0$  
$D = 25 + 144 = 169$  
$t = \frac{5 \pm 13}{2}$  
$t = 9$ (так как $t \geq 0$)

$x = \pm 3, \quad y = \mp 2$

**Ответ:** $z_1 = 3 - 2i, \quad z_2 = -3 + 2i$

*Дано:* $w \in \mathbb{C}, \quad n \in \mathbb{N}$  
*Найти:* $z \in \mathbb{C}, \quad z^n$

- $w = 0 \Rightarrow z = 0$
- $w \neq 0 \Rightarrow w = r \cdot (\cos \varphi + i \cdot \sin \varphi), \quad r > 0, \quad r\varphi \in \mathbb{R}$  
  $z = \rho \cdot (\cos \alpha + i \cdot \sin \alpha), \quad \rho > 0, \quad \rho,\alpha \in \mathbb{R}$  
  $w = z^n \Leftrightarrow \begin{cases} r = \rho^n \\ \varphi = n\alpha + 2\pi k, \quad k \in \mathbb{Z} \end{cases} \Leftrightarrow \begin{cases} \rho = \sqrt[n]{r} \\ \alpha = \frac{\varphi + 2\pi k}{n}, \quad k \in \mathbb{Z} \end{cases} \Leftrightarrow z = \sqrt[n]{r} \cdot (\cos \frac{\varphi + 2\pi k}{n} + i \cdot \sin \frac{\varphi + 2\pi k}{n}), \quad k \in \mathbb{Z}$  
  $k$ - можно взять $0,1, \ldots, n-1$ - тогда $z$ будут различными  

**Теорема.** Пусть $w \in \mathbb{C}, \quad n \in \mathbb{N}$  
1. Если $w = 0$, то уравнение $z^n = w$ имеет единственный корень $z = 0$
2. Если $w = r \cdot (\cos \varphi + i \cdot \sin \varphi), r, \varphi \in \mathbb{R}, r > 0$, то уравнение $z^n = w$ имеет ровно $n$ корней $z = \sqrt[n]{r} \cdot (\cos \frac{\varphi + 2\pi k}{n} + i \cdot \sin \frac{\varphi + 2\pi k}{n}), \quad k \in \{0,1, \ldots, n-1\}$  

$\mu_n = \{z \in \mathbb{C} | z^n = 1\} = \{cos \frac{2\pi k}{n} + i \cdot sin \frac{2\pi k}{n} | k \in \{0,1, \ldots, n-1\}\}$ - подгруппа в $\mathbb{C}^*$  
$\zeta, \zeta' \in \mu_n \Rightarrow (\zeta \cdot (\zeta'))^{-1})^n = \zeta^n \cdot ((\zeta')^n)^{-1} = 1 \Rightarrow \zeta \cdot (\zeta')^{-1} \in \mu_n$  

$\zeta_k = \cos \frac{2\pi k}{n} + i \cdot \sin \frac{2\pi k}{n}, \quad k \in \{0,1, \ldots, n-1\}$  
$\mu_n = \{\zeta_0, \zeta_1, \ldots, \zeta_{n-1}\}$  
$\zeta_k = \zeta_1^k$  
$\mu_n = \langle \zeta_1 \rangle$  

**Определение.** Пусть $n \in \mathbb{N}$. Число $\zeta \in \mathbb{C}$ называется *первообразным корнем* из $1$ степени $n$, если:
1. $\zeta^n = 1$
2. $\zeta^k \neq 1, k = 1, 2, \ldots, n-1$

$n = 6 \qquad \mu_6 = \{\zeta_0, \zeta_1, \ldots, \zeta_5\} \qquad \zeta_k = \zeta_1^k$  
$\zeta_1 = \cos \frac{2\pi}{6} + i \cdot \sin \frac{2\pi}{6}$  
$\zeta_1^k \neq 1, k = 1, 2, \ldots, 5$  
$\zeta_1^6 = 1$  
$\zeta_1$ - первообразный корень из $1$ степени $6$  
$\zeta_0^1 = 1$  
$\zeta_2 = \zeta_1^2 : \zeta_2^3 = \zeta_1^6 = 1$  
$\zeta_3 = \zeta_1^3 : \zeta_3^2 = \zeta_1^6 = 1$  
$\zeta_4^3 = 1$  
$\zeta_5 = \zeta_1^{-1}$ - перавообразный корень из $1$ степени $6$  

$n = 5 \qquad \mu_5 = \{\zeta_0, \zeta_1, \ldots, \zeta_4\}$   
$\zeta_1$ - первообразный корень из $1$ степени $5 \Rightarrow \zeta_4 = \zeta_1^{-1}$ - первообразный корень из $1$ степени $5$  
$\zeta_0$ - не первообразный корень из $1$ степени $5$  
$\zeta_2^1 = \zeta_2, \quad \zeta_2^2 = \zeta_4^1, \quad \zeta_2^3 = \zeta_6 = \zeta_1 \neq 1$  
$\zeta_2^4 = \zeta_8 = \zeta_3 \neq 1$  
Таким образом $\zeta_2$ - первообразный корень из $1$ степени $5$  
$\zeta_3 = \zeta_2^{-1}$ - первообразный корень из $1$ степени $5$  

**Предложение.** Пусть $\zeta \in \mu_n$. Тогда $\zeta$ - первообразный корень из $1$ степени $n$ $\Leftrightarrow \langle \zeta \rangle = \mu_n$  
**Док-во:**  
$\Rightarrow$  
$\zeta_1^0, \zeta_1^1, \ldots, \zeta_1^{n-1}$; предположим, что $\langle \zeta \rangle \neq \mu_n$  
Тогда $\exists k, l : \zeta_1^k = \zeta_1^l, 0 \leq k < l \leq n-1 \Rightarrow \zeta^{l-k} = 1, 0 < l-k < n$ - противоречие.  
$\Leftarrow$  
Пусть $\langle \zeta \rangle = \mu_n$  
Предположим, что $\zeta^k = 1, 1 \leq k < n$  
$\xi \in \mu_n \Rightarrow \xi = \zeta^j, 0 \leq j \leq n-1$  
$j = k \cdot q + r, 0 \leq r \leq k-1$  
$\xi = \zeta^{kq+r} = (\zeta^k)^q \cdot \zeta^r = \zeta^r 1 \Rightarrow \mu_n = \{\zeta_0, \zeta_1, \ldots, \zeta_{k-1}\} \Rightarrow |\mu_n| \leq k < n$ - противоречие.  

**Упражнение 1.** Пусть $k, n \in \mathbb{N}$
Тогда $\cos \frac{2\pi k}{n} + i \cdot \sin \frac{2\pi k}{n}$ - первообразный корень из $1$ степени $n$ $\Leftrightarrow \gcd(k, n) = 1$  
**Упражнение 2.** Пусть $n \in \mathbb{N}$.  
Тогда $\sum_{\zeta - \text{первообразный корень из } 1 \text{ степени } n} \zeta = \mu(n) = \begin{cases} 0, \quad \exists \text{ простой } p \vdots p^2 | n \\ (-1)^m, \quad n = p_1 \ldots p_m, p_i \text{ - различные простые} \end{cases}$  
*Подсказка:*  
$\sum_{\zeta - \text{первообразный корень из } 1 \text{ степени } n} \zeta = \nu(n)$  
$\sum_{\zeta^6 = 1} \zeta = 0 = \nu(6) + \nu(3) + \nu(2) + \nu(1)$
